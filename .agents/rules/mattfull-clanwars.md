When making changes make sure to follow these steps:

Without disturbing the connection to supabase, the domain name and the github actions that run in deployment. make sure the build is successful. Change the code in the entire repository that is added to the context. 

Do-not:
- Make changes that generate too many new interfaces and buttons which provide an over engineered feeling to the app.
- Write on site language in any other language than Swedish. 
- Have features that exceed page/web-app margins on the sides. 

Always test until the acceptence criteria has been followed and passed.
